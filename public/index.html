01 / Architecture

System architecture

An intelligence layer on top of ERPNext. The model reasons and requests actions; Frappe executes them under the user's existing permissions.

01User requestNatural-language question or in-form action
02Claude APIInterprets intent, selects a tool, returns structured JSON
03Orchestration layerValidates the call against an allow-list of scoped tools
04Frappe ORM / APIExecutes under the requesting user's roles and permissions
05ResponseResult returned to the model, then to the user
